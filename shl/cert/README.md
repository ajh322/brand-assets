## 마스킹 ★

공개 저장소라 **개인정보를 지우고 올렸다.** 원본은 로컬에만 있다.

| 문서 | 지운 것 |
|---|---|
| 보험증권 | 보험료·매출액 · 담당 설계사 이름/전화/메일 · 사업장 상세 주소 |
| 디자인등록증 | **생년월일(주민번호 앞자리) · 자택 주소** (권리자·창작자 두 곳) |
| 통신판매업 신고증 | **문서확인번호**(정부24 조회용) · 담당 공무원 이름/전화 |

- PDF(보험증권)는 `mask_cert_pdf.py` 로 **글자 자체를 지웠다**(apply_redactions).
  검은 칠만 덮으면 텍스트가 남아 복사·검색이 된다
- 스캔 이미지는 `mask_cert_img.py` 로 픽셀을 덮었다. 좌표가 해상도에 묶여 있어
  **파일을 다시 뽑으면 좌표부터 다시 잡아야 한다**

남긴 것 — 증빙에 필요하다: 회사명, 보험기간, 계약번호, 보상한도, 등록번호,
사업장 주소(통신판매업 표시의무로 어차피 공개되는 정보)

### KCL 성적서 — 국문만 올린다

원본 PDF 는 **같은 성적서의 국문판과 영문판 두 벌**이다.

| PDF 쪽 | 내용 |
|---|---|
| 1~3 | 시험성적서 `CT26-048681K` — 국문. **이것만 올린다** |
| 4~6 | TEST REPORT `CT26-048681E` — 영문. 올리지 않는다 |

영문판이 필요해지면 원본 PDF 4~6쪽을 같은 방식으로 뽑아 `-en-p01` 식으로
이름을 붙여 추가한다. 기존 파일명은 건드리지 않는다.

## 원본

- KCL 시험성적서 원본 PDF 는 저장소에 넣지 않았다(4.5MB). 필요하면 원본 파일을 쓴다
- PDF 는 150dpi 로 렌더한 뒤 폭 1600px 로 줄였다. 화면에서 도장과 표를 읽는 데는
  충분하고, 인쇄·제출용이 필요하면 원본 PDF 를 쓴다

⚠️ **파일명을 바꾸거나 지우지 않는다. 추가만 한다.** 한번 글이나 제안서에 링크가
박히면 못 바꾼다.
